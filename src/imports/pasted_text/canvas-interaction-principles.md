Принципы взаимодействия пользователя с бесконечным холстом
Обновлено 18 марта 2026, 01:37

1. Режимы инструментов
Холст работает в одном из активных режимов инструмента. Режим определяет, как интерпретируются все действия пользователя:

Указатель (default)

default

Выделение, перемещение элементов, вызов панелей

Рука

grab / grabbing

Панорамирование холста

Соединение

crosshair

Создание связей между элементами

Корреляция

default

Анализ влияния — подсветка цепочки зависимостей

A/B-тест

default

Выбор целевого элемента для эксперимента

2. Панорамирование (перемещение видимой области)
Режим «Рука» + ЛКМ зажата + движение мыши

Холст следует за курсором 1:1 (drag-to-pan)

Средняя кнопка мыши (колёсико-клик) зажата

Временно активируется режим «Рука» из любого другого режима. При отпускании — возврат в предыдущий режим

Отпускание кнопки

Панорамирование прекращается, pointer capture освобождается

Pointer Capture: при начале панорамирования контейнер холста захватывает указатель (setPointerCapture), чтобы движение за пределы окна продолжало работать. Освобождается при pointerUp или pointerLeave.

3. Масштабирование (зум)
Колёсико мыши (scroll)

Зум к точке курсора. Множитель: exp(-deltaY × 0.001). Диапазон масштаба: 0.1× – 5×

Кнопка «−» в панели зума

Уменьшение масштаба на 10% (×0.9) относительно центра холста

Кнопка «+» в панели зума

Увеличение масштаба на 10% (×1.1) относительно центра холста

Кнопка «Вписать»

Автоматический подбор масштаба и позиции так, чтобы все элементы поместились в видимую область с отступом. Масштаб ограничен диапазоном 0.05× – 1.5×. Учитывает зоны шапки (80px сверху) и подвала (100px снизу)

Зум к точке курсора: при зуме колёсиком точка под курсором остаётся неподвижной — трансформация пересчитывает смещение (x, y) относительно позиции мыши в контейнере.

Первоначальная подгонка: при первом рендере, если на холсте есть элементы, автоматически выполняется «Вписать».

4. Фон холста
Точечная сетка (radial-gradient), точки привязаны к трансформации холста.

Размер ячейки сетки: базовый 20px × масштаб. Если результат < 15px — размер удваивается (адаптивная плотность при отдалении).

5. Левая кнопка мыши (ЛКМ) — поведение по режимам
5.1 Режим «Указатель»
Клик по пустому пространству:

Снимает выделение со всех элементов

Закрывает боковую панель, панель групп и таблицу

Начинает область выделения (selection marquee)

Область выделения (marquee):

При зажатой ЛКМ и движении мыши рисуется полупрозрачный прямоугольник

Все элементы, чьи bounding box пересекается с прямоугольником, подсвечиваются как «предвыбранные»

При отпускании ЛКМ пересечённые элементы становятся выделенными (множественное выделение)

Если ни один элемент не попал — выделение остаётся пустым

Клик по элементу (быстрый, < 200мс):

Без модификаторов: выделяет этот элемент, открывает боковую панель

Клик по кнопке или зоне .no-drag внутри элемента: не инициирует перетаскивание

Зажатие ЛКМ на элементе + движение (> 200мс):

Начинается перетаскивание элемента

Если элемент входит в группу выделенных — перетаскиваются все выделенные элементы синхронно (сохраняя взаимное расположение)

Если элемент не выделен — перетаскивается только он

Смещение рассчитывается с учётом текущего масштаба: dx / scale

По окончании перетаскивания (отпускание ЛКМ) — состояние позиции фиксируется

5.2 Режим «Рука»
ЛКМ по любой области → панорамирование (см. раздел 2)

Клики по элементам игнорируются, перетаскивание элементов невозможно

5.3 Режим «Соединение»
Клик по элементу (1-й):

Элемент запоминается как источник связи

Появляется подсказка-баннер: «Источник выбран. Нажмите на целевой элемент»

От центра источника к курсору рисуется пунктирная линия-превью

Клик по элементу (2-й):

Если это тот же элемент → ошибка «Нельзя связать элемент сам с собой»

Если связь уже существует → ошибка «Связь уже существует», сброс источника

Иначе → связь создаётся, уведомление об успехе, сброс источника

Клик по пустому пространству (при выбранном источнике):

Сброс источника, линия-превью исчезает
Движение мыши (при выбранном источнике):

Пунктирная линия-превью обновляется от центра источника к текущей позиции курсора (в координатах холста)
5.4 Режим «Корреляция»
Клик по элементу:

1-й клик: выбирает целевой элемент (уведомление: «Выберите влияющий элемент»)

2-й клик: выбирает влияющий элемент, запускает расчёт

Наведение на элемент:

Подсвечивается вся цепочка зависимостей (все предки по связям) от наведённого элемента

Элементы, не входящие в цепочку целевого элемента, визуально приглушаются (dimmed)

Приглушённые элементы не реагируют на клики и перетаскивание

5.5 Режим «A/B-тест»
Клик по элементу:

Выбирает элемент как целевой для эксперимента

Открывает боковую панель

6. Средняя кнопка мыши (СКМ)
Нажатие

Если активен режим «Указатель» или «Соединение» — временно переключается в режим «Рука». Начинается панорамирование. preventDefault() блокирует браузерный авто-скролл

Движение с зажатой СКМ

Панорамирование холста

7. Правая кнопка мыши (ПКМ)
ПКМ по элементу

Открывает контекстное меню с действиями с элементом

ПКМ по пустому пространству

Открывает контекстное меню с действиями

8. Клавиатура
Delete / Backspace

Есть выделенные элементы, фокус не в текстовом поле

Показывает диалог подтверждения удаления. При подтверждении — удаляет все выделенные элементы

Escape

Режим «Соединение» с выбранным источником

Сбрасывает источник связи, убирает линию-превью

9. Элементы на холсте — поведение
Перетаскивание элемента:

Инициируется только ЛКМ (button === 0), только в режимах «Указатель», «Соединение», «Корреляция», «A/B-тест» (не «Рука»)

Порог: движение начинается только через 200мс после нажатия (защита от случайного перетаскивания при клике)

При групповом выделении — все выделенные элементы перемещаются на одинаковый вектор смещения

Элементы внутри кнопок и .no-drag-зон не инициируют перетаскивание

Расширенное состояние элемента (expand):

Элемент визуально расширяется при выделении, если: он единственный выделенный, нет активной области выделения (marquee), нет режима «Соединение»
10. Панель зума (левый нижний угол)
Четыре кнопки, всегда поверх холста (z-index):

Минус — зум ×0.9

Вписать — автоподгонка всех элементов в видимую область

Плюс — зум ×1.1

Авто-раскладка — пересчёт позиций всех элементов по алгоритму автоматической раскладки, затем «Вписать»

Все кнопки блокируют propagation pointerDown, чтобы нажатие не инициировало панорамирование или выделение на холсте.

11. Блокировка propagation
Боковая панель

pointerDown, mouseDown — клики в панели не влияют на холст

Кнопки зума

pointerDown — не начинают панорамирование

Кнопки/интерактивные зоны внутри элементов

pointerDown через проверку .closest('button') / .no-drag

Контекстное меню

Обрабатывается обёрткой, не передаётся на холст
