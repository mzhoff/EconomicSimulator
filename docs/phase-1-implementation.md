# Phase 1: реализованный результат

## Коротко

EconomicSimulator теперь запускается не как SaaS-демо с `price`, `CAC` и
`churn`, а как локальная месячная модель экономики одной станции TokBeri.

Внешне это тот же визуальный Canvas. Внутри формулы больше не являются
JavaScript-функциями, спрятанными в React-компоненте. Модель целиком
сериализуется в JSON, проверяется до расчёта и может быть восстановлена после
закрытия браузера.

## Что уже работает

### Экономика TokBeri

- сценарии `Weak`, `Base`, `Good`, `Hotspot`;
- успешные аренды, тарифный микс и средний чек;
- комиссия площадке и эквайринг;
- сценарный резерв или событийный режим потерь;
- износ батарей через полезные циклы;
- SIM, обслуживание, ребалансировка и прочий OPEX;
- CAPEX станции, батарей, доставки, монтажа и стартового запаса;
- денежный вклад станции;
- прибыль до налогов;
- окупаемость через положительный денежный вклад;
- предупреждения capacity и целочисленного количества батарей;
- депозит как отдельная справочная метрика, не входящая в rental revenue.

Франшиза, HQ и налоги намеренно не считаются доверенным результатом.

### What-if

- любой input можно менять ползунком или точным числом;
- сценарий сравнивается с Base;
- доступны относительный, абсолютный и percentage-point shock;
- downstream-путь подсвечивается до выбранной North Star;
- North Star можно поменять в инспекторе или через контекстное меню;
- автоматически находятся:
  - безубыточные аренды в день;
  - аренды в день для payback не более 12 месяцев;
  - аренды в день для payback не более 24 месяцев.

### Надёжность

- schema version `1`;
- сериализуемый AST формул;
- calculation edges автоматически выводятся из AST;
- строгая топологическая сортировка;
- цикл блокирует расчёт и импорт;
- несовместимые единицы блокируют формулу;
- `Event` нельзя использовать как обычное число;
- ошибка становится видимой, а не превращается в ноль;
- autosave с debounce в версионированный `localStorage`;
- последняя валидная копия;
- backup перед импортом/миграцией;
- безопасный JSON import;
- JSON export сохраняет формулы, сценарии, позиции и viewport.

### Canvas

- zoom к курсору через `Ctrl/⌘ + wheel`;
- экранно-постоянные толщина линий и размер стрелок;
- сплошные `Calculation` и пунктирные `Influence`;
- путь к North Star без выбора;
- upstream/downstream-фокус для одной метрики;
- calculation-путь между несколькими выбранными метриками;
- знак и сила изменения в Impact Mode;
- красные расчётные ошибки и янтарные guardrail-пути;
- подписи связей и подсветка крайних карточек при наведении;
- pan колесом и средней кнопкой;
- box selection;
- `Shift` multi-select;
- групповое перетаскивание;
- контекстное меню;
- undo/redo для изменений модели и раскладки;
- auto-layout по calculation DAG.

Кнопка ручного соединения calculation-узлов намеренно выключена. Расчётная
связь не должна существовать отдельно от формулы: сейчас она появляется только
из AST. Безопасный визуальный редактор формул и связей относится к Phase 2.

## Контрольный Base

Контрольный fixture находится в
`src/core/fixtures/tokberi-base-station.json`.

При `1,5` аренды в день модель получает:

| Метрика | Результат |
|---|---:|
| Успешные аренды | 45 |
| Средний чек | 247 ₽ |
| Арендная выручка | 11 115 ₽ |
| Денежный вклад | 7 257,23 ₽ |
| Прибыль до налогов | 6 846,11 ₽ |
| CAPEX | 14 800 ₽ |
| Payback | 2,04 месяца |

Это рабочая модель порядка величин, а не окончательный инвестиционный вывод.
Тариф, потери, обслуживание и другие допущения должны уточняться по факту.

## Как устроено простыми словами

```text
JSON-модель
    ↓
проверка схемы, единиц и циклов
    ↓
расчёт чистым TypeScript-движком
    ↓
сценарии / sensitivity / thresholds
    ↓
React показывает результат на Canvas
```

React отвечает за интерфейс. `src/core` отвечает за экономический смысл и не
зависит от React. Поэтому ядро можно тестировать отдельно, а в будущем
перенести в Web Worker или backend без переписывания формул.

Next.js на локальном этапе не нужен. Он не улучшит математику, Canvas или
localStorage, но добавит серверные сущности, которые пока нечем оправдать.

## Локальная проверка

```bash
npm install
npm test
npm run typecheck
npm run build
npm run dev
```

Автоматические тесты проверяют эталонную экономику, все четыре сценария,
sensitivity, thresholds, запрет циклов, несовместимые units, запрет арифметики
с Event и JSON round-trip.

## Что дальше

Ближайшая практическая работа — не новый фреймворк, а уточнение паспорта
допущений TokBeri и создание безопасного редактора произвольных формул. После
этого можно переходить к нескольким моделям, фактическим данным, time-series и
импорту событий.
