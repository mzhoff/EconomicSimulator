# EconomicSimulator

Локальный визуальный инструмент для моделирования экономики продукта, пирамид
метрик, сценариев и влияния управляемых параметров на выбранную ключевую
метрику.

Текущий интерфейс — рабочий локальный конструктор. Стартовый экран намеренно
сведён к минимальной модели денежного потока TokBeri: доходы, расходы и прибыль.
Детали экономики добавляются пользователем постепенно, без перегруженного
стартового графа.

Исходный UI-прототип был подготовлен в
[Figma](https://www.figma.com/design/wcQ8FAO2ScDloBwRJHylwM/Interactive-Metric-Modeling-Tool).
Лицензии использованных компонентов и материалов перечислены в
[ATTRIBUTIONS.md](ATTRIBUTIONS.md).

## Зафиксированные решения

- пока остаёмся на React + Vite;
- продукт в первую очередь локальный;
- текущий дизайн сохраняется;
- расчётные формулы будут сериализуемыми и типобезопасными;
- расчётные зависимости образуют DAG, циклы запрещены;
- причинные связи хранятся отдельно и в будущем могут содержать циклы;
- сохранение, импорт и экспорт первой версии работают через JSON и
  `localStorage`;
- первый прикладной шаблон — минимальный денежный поток TokBeri без
  недостоверного франчайзингового слоя;
- в пользовательском графе используются `Stock / Flow / Rate / One-off`;
- детальные денежные категории можно хранить компактной таблицей и
  разворачивать в обычный расчётный подграф на Canvas;
- месячный денежный результат можно повторить в `Monthly Timeline`, добавить
  календарь CAPEX и получить накопительный график окупаемости;
- амортизация и бухгалтерский учёт в текущей временной модели намеренно не
  используются;
- `Event` отложен до отдельного слоя импорта сырых данных.
